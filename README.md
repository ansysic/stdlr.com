# stdlr.com

A minimal, responsive page showing the Leslie Nielsen “Nothing to see here” meme.

## Preview locally

Open `index.html` in a browser. No installation or build is required.

## Deployment

GitHub Pages serves `index.html` directly from `main / (root)`.
`.nojekyll` disables Jekyll, and `CNAME` sets the custom domain to `stdlr.com`.
The styles are embedded in `index.html`; the image is stored in `public/`.
